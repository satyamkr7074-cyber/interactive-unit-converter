# Interactive Unit Converter

An Interactive Unit Converter built using HTML, CSS, and JavaScript. It allows users to quickly convert values between different units with a simple and responsive interface.

## 🚀 Live Demo

https://satyamkr7074-cyber.github.io/interactive-unit-converter/

## 📂 GitHub Repository

https://github.com/satyamkr7074-cyber/interactive-unit-converter

## ✨ Features

- Instant unit conversion
- Length conversion
- Weight conversion
- Temperature conversion
- Speed conversion
- Area conversion
- Time conversion
- Swap units functionality
- Clear button
- Input validation
- Responsive design
- Clean and user-friendly interface
- Works on desktop, tablet, and mobile devices

## 💻 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Select a conversion category.
5. Enter a value and select the required units.
6. The converted result will be displayed instantly.
